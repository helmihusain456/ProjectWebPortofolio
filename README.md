## ✨ Fitur Utama

- **🏠 Home & Pemesanan (`home.html`)**  
  Katalog layanan desain dengan pencarian *real-time*, form pemesanan otomatis, unggah bukti bayar, serta cetak ringkasan pesanan (PDF).
- **👥 Profil Tim Dinamis (`about.html`)**  
  Menampilkan profil tim inti serta form tambah anggota baru yang tersimpan otomatis menggunakan `localStorage`.
- **📩 Kontak & Validasi (`contact.html`)**  
  Form kontak dengan validasi input ketat (Email & WhatsApp) serta proteksi sanitasi XSS.

## 📁 Struktur File

```text
ProjectWebPortofolio/

├── hasil.html                  # Halaman konfirmasi anggota baru
├── contact.html / .css / .js   # Halaman & validasi form kontak
└── README.md                   # Dokumentasi proyek
```

## 🚀 Cara Menjalankan

1. **Clone repositori**
   ```bash
   git clone https://github.com/helmihusain456/ProjectWebPortofolio.git
   ```
2. **Buka proyek**  
   Masuk ke folder `ProjectWebPortofolio`, lalu klik dua kali pada file `home.html` atau jalankan menggunakan ekstensi **Live Server** di VS Code.
